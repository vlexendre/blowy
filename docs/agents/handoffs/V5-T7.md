## Architecture
- `apps/mobile/src/features/<f>/{api,model,ui}` (+ `adapters/` quand un port existe) ; chaque feature n'expose que son `index.ts` (les imports croisés internes restants ont été remplacés : home→settings, onboarding→pets/account, core→onboarding/settings). Les tests d'intégration importent directement les dépôts (`api/*.repository.ts`) pour ne pas charger l'UI dans Node.
- Composants répétés remontés dans `packages/ui-mobile` (atomes → molécules → organismes → gabarits). Ajouts T7 : molécules `NoteCard`, `ChoicePills`, `Row.valueWeight`, `StepTag.progress=null`, `AuthButton.disabled` ; organismes `share.tsx` (`ShareCard`, `ShareNotes`, `ShareActions`, `GroupTableArt`, `TableOfFiveArt`, `TableOfFiveInkArt`, `SecretEnvelopeArt`, `CheckRowsArt`) ; gabarit `ShareScreen`.
- Écrans V4 coupés : isolés dans `apps/mobile/legacy-v4/` (non routés, hors tsconfig/lint, README) — la suppression a été refusée par le classificateur de permissions.
- RevenueCat (`features/purchases`) **désactivé** (V5.4 §C11) : code conservé, plus monté par `AppProviders`, aucun écran ne l'importe.

- `EXPO_PUBLIC_STRIPE_PUBLISHABLE_KEY` (validée `^pk_(test|live)_`, jamais une clé secrète) et `EXPO_PUBLIC_APPLE_MERCHANT_ID` (public).
